# Wildhaven

A lightweight, asset-free 3D open-world exploration game for the browser.

## Play

Serve the project from a local web server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- **WASD** — Move
- **Shift** — Sprint
- **Mouse** — Look around
- **Esc** — Release mouse lock

Explore the procedurally shaped valley and restore all five ancient waystones.
